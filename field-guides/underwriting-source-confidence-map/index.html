Map confidence in underwriting sources

Not every model input deserves the same confidence. A source map records whether a number comes from reconciled history, a current quote, a comparable or an unsupported estimate. The aim is to make uncertainty visible and prioritize research, not to turn a subjective score into a promised investment outcome.

Work through the decision

  1. Label the source type for each input.
  2. Record its date and property relevance.
  3. Identify high-impact unsupported inputs.
  4. Update the map when better evidence arrives.

For each action, name the person responsible for preparing the response and the person who approves it. Record what evidence would close the item. If new information changes cost, timing or scope, update the affected plan and identify who needs the revised version.

Common failure to avoid

A large volume of comparable listings does not resolve a mismatch in dates, property features or revenue definitions. Record relevance as well as quantity.

Worked example

An illustrative model uses an insurer quote for coverage cost and an unverified revenue estimate. The map makes the evidence difference visible and prioritizes revenue reconciliation before capital is committed.

Close the handoff

A finished worksheet should identify the result, its evidence and any remaining owner. If the result is uncertain, record the next action instead of marking the whole task complete. Keep the worksheet with the relevant source file and tell the receiving person which version applies.
