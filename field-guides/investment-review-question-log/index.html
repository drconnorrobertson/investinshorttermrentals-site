Keep a decision-focused investment question log

A review meeting becomes more useful when unresolved questions have owners and evidence requirements. Write questions that can be answered with a document, calculation or explicit decision. Preserve answers and source references so the same issue is not repeatedly reopened without new information.

Work through the decision

  1. Write one decision-relevant question per row.
  2. Name the evidence needed.
  3. Assign a response owner.
  4. Record the answer and its effect on the model.

For each action, name the person responsible for preparing the response and the person who approves it. Record what evidence would close the item. If new information changes cost, timing or scope, update the affected plan and identify who needs the revised version.

Common failure to avoid

A question such as “is this a good deal?” is too broad to close. Break it into the assumptions and tradeoffs the owner actually needs to assess.

Worked example

In an illustrative review, a question about operating cost becomes a request for the current management fee base and add-on schedule. The answer is linked to the cost model before the next owner decision.

This is an illustrative workflow, not a client case study or a forecast. Replace the example’s facts with the records for your own project.

Close the handoff

A finished worksheet should identify the result, its evidence and any remaining owner. If the result is uncertain, record the next action instead of marking the whole task complete. Keep the worksheet with the relevant source file and tell the receiving person which version applies.
